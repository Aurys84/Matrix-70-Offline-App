# 🚀 Matrix-70-App | A&N Visual Global (EN)

Welcome to the future! The **Matrix-70-App** is a joint development of A&N Visual and Cs-Aion Lab. It is a professional career engine designed with pinpoint logic and aesthetics to help achieve global success.

## ✨ Why Matrix-70?
- **3-Language Matrix**: Full HU, EN, and DE support for both the interface and generated content.
- **Matrix Summary Selector**: 15 pre-calibrated professional summaries that instantly adapt to the selected language.
- **Global Matrix Layouts**: 15 selectable visual styles, ranging from minimalist to premium hospitality looks.
- **PWA Technology**: Installable as a Web App with manifest support for a native mobile experience.

## 🛠️ Technical Stack
- **Engine**: Pure JavaScript (built on the Zero-Guessing logic principle).
- **Data**: Dynamic `database.js` with a modular structure for flexible expansion.
- **Style**: Dynamic CSS variables (`--main-color`) for complete visual customization.

## 📱 Installation Guide
1. Open the URL generated by GitHub Pages.
2. On **Android**: select "Add to Home Screen".
3. On **iOS**: select "Add to Home Screen" from the Share menu.
4. Launch the Matrix-70-App directly from your home screen!
